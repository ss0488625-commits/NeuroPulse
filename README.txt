NEUROPULSE - Brain Training Games
=================================
Files
  index.html  page structure and text
  style.css   dark slate + emerald + amber theme, layout and animations
  script.js   the 9 games, XP, levels, streaks, badges, charts, sound

Run it
  1. Keep the three files in one folder.
  2. Double-click index.html (opens in your browser), OR
     in VS Code install the "Live Server" extension, right-click index.html -> "Open with Live Server".

Publish it free
  Netlify Drop: go to app.netlify.com/drop and drag the whole folder in.
  GitHub Pages: push the folder to a repository, then Settings -> Pages -> Deploy from branch (main, / root).
  Vercel: vercel.com -> Add New -> Project -> upload / import the folder.

Customise
  Colours: top of style.css, the :root { --bg, --green, --amber ... } variables.
  Games / names: the GAMES list at the top of script.js.
  Reset saved progress: use the "Reset all progress" button on the page.
