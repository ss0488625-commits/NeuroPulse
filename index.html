    An honest note

    Brain games are a fun way to practise focus, memory and speed. Research on whether they improve everyday thinking is mixed, so treat this as friendly mental exercise. Sleep, movement, learning new skills and time with friends matter just as much.

    Is NeuroPulse free?

    Yes. There are no ads, accounts or payments.

    Where is my progress saved?

    In your browser’s local storage on this device. Clearing site data or using a different browser starts you fresh.

    How is the Brain Score calculated?

    It averages your best result in all nine games, scaled to 100. Games you haven’t played count as zero, so trying every game raises your score.

    Can I use my keyboard?

    Yes. Sequence Memory uses Q, W, A, S. Reaction Time uses Space. Math Sprint uses Enter, and Stroop uses the number keys. Aim Trainer, Odd One Out and Number Order are played with the mouse or touch. Press Esc to leave a game.
